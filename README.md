# 【Windows専用】CsvColumnShaper GUI ｜ 氏名・住所・電話番号 正規表現一括列分割＆クレンジング機

> **「1つのセルに固まった住所を、ヤマトのB2クラウドや佐川のe飛伝用に『番地』と『マンション名』に手作業で切り分けるのが苦痛すぎる…」**  
> **「顧客名簿の『山田 太郎 様』から敬称を消して『姓』と『名』に分けたいが、関数やVBAを書く知識がない…」**  
> **「ハイフンが抜けたりバラバラな電話番号を、市外局番や携帯電話のルールに合わせて一発で綺麗に揃えたい…」**

『CSV ColumnShaper GUI』は、EC通販の出荷担当者・営業事務・情シス・CRM移行担当者のために開発された、**氏名・住所・電話番号を正規表現と内蔵辞書で高精度に一括列分割・クレンジングするWindows専用ポータブルGUIツール**です。

面倒なインストール作業やPython環境の構築は一切不要。解凍してダブルクリックするだけですぐに使えます。

## 💡 このツールで解決できるお悩み

- **ヤマト・佐川の送り状システム用「住所4分割」を一瞬で完了**:
  - 全国の都道府県辞書と正規表現により、「都道府県」「市区町村」「番地」「建物名・部屋番号」に高精度4分割。配送伝票の「住所1」「住所2」へのコピペ手作業（数時間〜半日）がワンクリックで終わります。
- **住所先頭の「郵便番号混入」を自動救出**:
  - フォーム入力や古いシステムで住所の先頭に混ざってしまった「〒100-0001」「100-0001」を自動検知。独立した「郵便番号」列として抜き出し、住所本体から綺麗に除去します。
- **氏名の「姓・名分割」＆「敬称（様・殿）自動除去」**:
  - 全角・半角スペースを認識して姓と名に自動分割。末尾の「様」「殿」「御中」も自動除去するため、DM発送や一斉メール送信時の「様 様」といった二重敬称事故を未然に防ぎます。
- **電話番号のハイフン自動付与・統一**:
  - 携帯電話（090/080/070）、東京・大阪（03/06）、地方主要都市（3桁局番）、一般固定（4桁局番）、フリーダイヤル（0120）を自動識別し、美しいハイフン付き表記に統一します。
- **実務監査用「_要確認フラグ」列を自動生成**:
  - 万が一「氏名にスペースがなく分割できなかった行」や「電話番号の桁数が足りない異常行」があった場合、末尾のフラグ列に理由を明記。Excelのオートフィルターで絞り込むだけで、手作業チェックが必要な行を一発で特定できます。

## 🛠️ 主な機能・特徴

1. **住所の「3分割 / 4分割」ワンクリック切り替え**
   - **4分割モード（EC・物流特化）**: 都道府県 / 市区町村 / 番地 / 建物名・部屋番号
   - **3分割モード（標準データ移行）**: 都道府県 / 市区町村 / 番地建物
2. **完全な文字化け防止（UTF-8 with BOM & Excel同時出力）**
   - 出力CSVは日本のExcelで直接ダブルクリックしても絶対に文字化けしない「UTF-8 with BOM（utf-8-sig）」を採用。さらにExcelブック（.xlsx）も同時にZIP同梱されます。
3. **半角カナ・全角英数の自動正規化（NFKC）**
   - 機種依存文字やシステムエラーの原因となる半角カナを全角カナへ、全角英数を半角英数へ自動クレンジング。
4. **安心の非破壊・完全ローカル処理**
   - 元のファイルを上書きせず、別名ファイルおよびZIPアーカイブとして出力。外部通信は一切行わず、すべてのデータはお使いのPC内でのみ処理されます。

## 🚀 使い方（3ステップで完了）

1. **対象ファイルの選択**
   - 「1. 対象ファイルの選択（CSV / TSV / Excel）」に分割・整形したいファイルをドラッグ＆ドロップします。
2. **対象列とモードの確認**
   - 住所列、氏名列、電話番号列を指定します（列名から自動推測してセットされます）。
   - 配送伝票用にマンション名を分けたい場合は「4分割モード」を選択します。
3. **実行とダウンロード**
   - 「🚀 一括列分割＆データ整形を実行」をクリックします。
   - 画面上に変換前後のプレビューテーブルと確認フラグが表示されたら、「📦 整形済みCSV・Excel・レポートを一括ダウンロード (ZIP)」をクリックして保存します。
